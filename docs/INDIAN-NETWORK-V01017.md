## Result and data meaning

Sixteen additional shipping paths and sixteen undersea paths connect existing offshore reference anchors around Dar es Salaam, Durban, Maputo and Port Elizabeth with Kochi, Chennai, Medan and Perth. The total is now 470 shipping and 378 cable paths. The 2,440 air connections and default moving budgets are unchanged. Actual visible particles still depend on saved settings, overall density, progressive activation and the visible hemisphere.

These are **illustrative connections**, not current services, actual ports, surveyed cables, AIS tracks or measured traffic. The previous atlas and original network files remain unchanged. `scripts/build-indian-branches.mjs` reuses their coastal endpoints, checks every new great-circle leg against the bundled ETOPO mask at a maximum 0.0002-radian spacing, and writes a separate public JSON disclosure/data file and a typed runtime copy. The runtime copy keeps the addition in the existing optional atlas load without another request. Failure to load that atlas still retains the original core network.

## Geometry and material

- Opposing compatible hub approaches share a through tangent. Other bearing groups remain independent; the existing water check can reduce a connector when coast constraints require it.
- Ten more Indian Ocean feeder spines and four revised southern approaches extend the existing display-spine scheme. Cape–Perth has a broader southern bow. Original records and endpoints stay fixed; rejected display spines fall back to the originals.
- Companion spacing grows with the length of a crossing. A coast or shallower seafloor patch now narrows only its neighbourhood, with smooth shoulders recovering the fan offshore. The complete regenerated strand is water/depth checked; it is omitted if a safe result cannot be found within the bounded attempts.
- Distinct source routes still drive moving travellers, using the same prepared geometry as their centre line. Decorative companion strands do not imply more routes or travellers. Route hierarchy and companion brightness retain the existing colours and thin cores.
- No control schema, density budget, satellite size, loading choreography or responsive layout changes.
